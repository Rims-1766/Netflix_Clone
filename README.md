# 🎬 Netflix Clone

A fully responsive Netflix-inspired landing page built using HTML and CSS.
This project recreates the modern Netflix UI with multiple sections, responsive layouts, and clean styling.

---

## 🚀 Live Demo

🔗 [Live Website](https://super-gaufre-c1660d.netlify.app/)

---

## 📌 Features

* Responsive design for mobile, tablet, and desktop
* Modern Netflix-inspired UI
* Hero section with background overlay
* Multiple content sections
* Hover effects on buttons
* Footer with navigation links
* Clean and structured layout

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* Flexbox
* Media Queries
